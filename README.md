# Журнал напоїв

Особистий облік напоїв, які ми спробували: смак, оцінка, ціна й нотатки.

Записи зберігаються в браузері (`localStorage`), без акаунта і сервера.

Живий сайт: [https://natalinamatioshko.github.io/drinks-app/](https://natalinamatioshko.github.io/drinks-app/)

## Що можна робити

- додавати напій: назва, категорія, бренд, місце, дата, ціна в ₴, оцінка смаку 1–10, коментар
- шукати, фільтрувати за категорією, сортувати за датою / оцінкою / ціною
- бачити статистику: скільки спробували, середня оцінка, скільки витратили
- редагувати або видаляти запис

## Запуск локально

```bash
npm install
npm run dev
```

Відкрий [http://localhost:3000](http://localhost:3000).
